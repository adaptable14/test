
# AIHub – Quản lý các Model AI
![Logo AIHub](web/images/logo-ai-hub.png)

Hệ thống **quản lý model** *trí tuệ nhân tạo* chạy tại `web/index.html`.

## Cấu trúc thư mục

| Thư mục | Nội dung |
|---|---|
| docs | Tài liệu bàn giao |
| data | Bảng tính quản lý model |
| logs | Log vận hành model AI |

## Liệt kê dự án

```powershell
Get-ChildItem -Force -Recurse
```
